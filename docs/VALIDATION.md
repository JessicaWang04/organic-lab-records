# 验证范围

本项目区分本地工具测试、宿主模型任务和原生绘图软件验收。一个层次通过不能替代其他层次。

| 范围 | 状态 |
|---|---|
| TypeScript 构建、记录、计量、交付验收与恢复 | v0.1.2 构建通过，83 项测试通过，含真实 Python 交付集成测试 |
| Python 化学工具与 CDXML 读回 | 16 项测试通过；含真实 PNG 裁剪、分步结构/立体/方向与条件验收 |
| 工作台与预算模拟 | 5 项检查通过，不调用真实模型 API |
| ZIP 解压后依赖启动、OpenCode 命令安装与重复安装保护 | 隔离目录测试已通过 |
| OpenCode 使用 Qwen / DeepSeek 完整整理新文献 | 尚未完成真实宿主对比测试 |
| 复杂桥环、差向异构体的来源图识别准确率 | 尚未完成具有人工参考答案的基准 |
| 原生 ChemDraw 中打开、编辑及重新保存 CDXML | 完整验收尚未完成 |
| 新电脑从环境安装到完整文献交付 | 尚未完成跨设备验收 |

RDKit 能解析输入、核对质量及读回导出结构，但不能独自证明模型识别的结构与原图一致。反应 PNG 也不能替代 CDXML 在目标软件中的显示验证。

v0.1.2 的拒绝测试覆盖整页 PDF 替代反应图、伪造通过标记、空白/损坏/位图 CDXML、错误连接或立体结构、反应方向交换、条件不一致、笔记缺 CDXML 链接和已完成缓存失效。旧 source-image-only 会话重新验收时会标为未完整交付，不自动覆盖旧实验笔记。

贡献质量评测时，应固定来源和裁剪，为每个结构建立人工核对的连接、立体信息及证据；分别统计完成覆盖率、连接准确率、立体信息准确率、关键投料错误、人工复核时间及端到端耗时。不要以全部弃答换取高准确率，或只展示挑选出的成功案例。

Bug 报告可提供 DOI、匿名化的最小输入、模型版本及错误字段。不要提交密钥、私人实验笔记或不允许公开的完整论文文件。
